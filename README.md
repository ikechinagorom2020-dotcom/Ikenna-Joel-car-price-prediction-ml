# 🚗 Car Price Prediction

## Project Overview

This project is a Machine Learning application that predicts the selling price of used cars based on their characteristics.

The project was developed as part of my Machine Learning course and demonstrates the complete Machine Learning workflow, from data preparation to deployment.

## Dataset

The dataset used for this project was obtained from Kaggle.

Dataset: Car Price Prediction Dataset  

Source:
https://www.kaggle.com/datasets/sukhmandeepsinghbrar/car-price-prediction-dataset

## Project Workflow

The project followed these steps:

1. Data collection
2. Data cleaning
3. Exploratory Data Analysis (EDA)
4. Data preprocessing
5. Train-test splitting
6. Model training
7. Model evaluation
8. Model comparison
9. Model serialization
10. Streamlit deployment

## Models Used

### Linear Regression

R² Score: 0.548

### Random Forest Regressor

R² Score: 0.919

Random Forest Regressor was selected as the final model because it performed significantly better than Linear Regression.
